# Игровая база предметов

Локальный Database Builder + Database Viewer для создания связанной базы предметов, рецептов, навыков, оборудования, способов получения и цен. Это фундамент будущего Craft Engine; расчёт цепочек в первую версию не входит.

## Состояние

Первая рабочая версия 0.1.0 завершена. Реализованы Database Builder, Database Viewer, справочники, предметы, альтернативные рецепты, изображения, поиск, фильтры, быстрое обновление аукционной цены и резервные копии. Исправление интерфейса после 0.1.0 устраняет падение при изменении числовых полей и нежелательные подложки текста. Расчёт цепочек крафта намеренно не входит в эту версию.

## Требования

- Python 3.12+
- Windows 10/11, Linux или macOS с поддержкой PySide6

## Быстрый запуск в Windows

1. Установите Python 3.12 или новее с официального сайта и включите добавление Python в `PATH`.
2. Один раз запустите `install.bat`.
3. Для работы запускайте `run.bat`.

Либо выполните вручную:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
python main.py
```

Приложение запускается в пользовательском режиме. Для редактирования нажмите постоянно видимую кнопку `Войти как администратор` в верхней панели и введите начальный пароль `admin`. Текущий режим отображается рядом: `VIEWER · ТОЛЬКО ЧТЕНИЕ` или `ADMIN · РЕДАКТОР`. Сразу после первого входа рекомендуется выбрать `Настройки → Сменить пароль администратора`.

Пароль не хранится открытым текстом: в `data/settings.json` находится salted PBKDF2-хэш.

## Основной сценарий

В режиме администратора:

1. Откройте `Справочники` и заполните столы, группы, подгруппы, навыки и оборудование.
2. Нажмите `+ Предмет`, заполните карточку и при необходимости выберите изображение или нажмите `Вставить скриншот` после его копирования в буфер. Также можно выделить preview изображения и нажать `Ctrl+V`.
3. Отметьте несколько способов получения и укажите независимые цены.
4. Нажмите `+ Добавить рецепт`, выберите существующие предметы-ингредиенты или напечатайте новые названия и заполните требования. Для новых ресурсов при сохранении появится один диалог группы/подгруппы. В обоих полях можно выбрать существующее значение или написать новое: новые группа и подгруппа добавятся в `Справочники`, ресурс станет полноценным Item и сразу свяжется с рецептом.
5. Используйте `Сохранить` или `Сохранить и создать следующий`.

Справочники можно дополнять, не закрывая редактируемую карточку. После закрытия окна `Справочники` варианты в уже добавленных строках рецепта обновятся автоматически; введённые названия, уровни, опыт и количества сохранятся.

В пользовательском режиме игровые поля и административные кнопки скрыты/заблокированы. Для рыночного предмета нажмите `✎` рядом с аукционной ценой, введите значение и нажмите Enter. Время обновления отображается под ценой.

Поиск работает по предмету, группе и подгруппе без учёта регистра. Все фильтры можно комбинировать.

## Данные и безопасность

- Основная БД: `data/database.db`.
- Изображения предметов: `data/images/items/`.
- Настройки локального пароля: `data/settings.json`.
- Резервные копии: `backups/`.
- Технический журнал: `logs/app.log`; при неожиданной ошибке в нём сохраняется полный traceback, а окно ошибки показывает её тип и сообщение.

Используйте `Файл → Создать резервную копию базы`. Копия создаётся SQLite Backup API и проходит `integrity_check`. `Файл → Открыть папку данных` открывает каталог с БД и картинками.

В рабочей БД уже находится небольшой демонстрационный набор из задания. Его можно повторно/идемпотентно создать командой:

```powershell
python scripts\seed_demo.py
```

## Разработка и тесты

```powershell
python -m pytest
alembic upgrade head
alembic check
```

Набор содержит 26 автоматических тестов: миграции, FK, CRUD, сложный рецепт, атомарное quick-create ингредиентов, разрешённые самоссылки, изображения и clipboard, Unicode-поиск, фильтры, режимы, сигналы редактора, аварийный журнал, цены после повторного открытия и backup.
