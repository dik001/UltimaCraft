# Итог разработки

Готова первая рабочая версия Database Builder + Database Viewer.

Основное:

- Полная реляционная SQLite-база с Alembic-миграциями.
- Справочники, предметы, изображения, несколько способов получения и раздельные цены.
- Несколько рецептов на предмет, ингредиенты строго через `Item ID`.
- Навыки, награды опыта и оборудование.
- Тёмный Builder UI, дерево, поиск и все требуемые фильтры.
- Viewer Mode с заблокированными игровыми данными.
- Быстрое изменение аукционной цены по `✎` и Enter.
- Пароль администратора хранится как PBKDF2-хэш.
- Backup через SQLite API с проверкой целостности.
- Демонстрационная база: 4 предмета, сложный рецепт и изображение.
- 19 тестов пройдены, `alembic check` чист, `PRAGMA integrity_check = ok`.

Запуск:

1. Запустить `install.bat`.
2. Затем `run.bat`.
3. Начальный пароль администратора: `admin`.

Документация: `README.md`, `ARCHITECTURE.md`, `TASKS.md`.

Расчёт цепочек крафта намеренно не реализован — текущая версия является фундаментом для будущего Craft Engine.
